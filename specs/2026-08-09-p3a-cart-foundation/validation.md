# P3a — Cart foundation (validation)

Pure logic is proven by unit tests (no DB). Anything touching Prisma is verified with
`npm run preview` (OpenNext + local Workers), **never `npm run dev`** — plain `next dev` can't load
`@prisma/client/wasm` and DB routes silently render an error state (`CLAUDE.md`). Host-dependent and
two-vendor checks run on staging, as in slices 3b/3c. DB assertions use `DIRECT_URL` against the
seeded target.

| Req | How to verify |

| R1  | `grep -A14 "model Cart " prisma/schema.prisma` shows `vendorId`, nullable `userId`/`guestToken`, both composite uniques and `@@index([vendorId])`; `npx prisma validate` exits 0. |
| R2  | `grep -A12 "model CartItem" prisma/schema.prisma` shows the FKs, `@@unique([cartId, productId])`, `@@index([cartId])`, and **no** price/amount/pence field (`grep -iE "price|pence|amount" ` over the model block returns nothing). |
