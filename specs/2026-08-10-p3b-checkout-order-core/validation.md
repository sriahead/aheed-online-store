# P3b — Checkout + order core (validation)

Pure logic is proven by unit tests (no DB). Anything touching Prisma is verified with
`npm run preview` (OpenNext + local Workers) or on staging — **never `npm run dev`**, which cannot
load `@prisma/client/wasm` (`CLAUDE.md`). DB assertions run against the seeded target via
`DIRECT_URL`. **Staging's `VendorConfig` delivery columns must be seeded first**, or every totals
row below reads zeros.
