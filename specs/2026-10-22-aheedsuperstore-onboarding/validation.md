# Aheed Super Store test vendor — placeholders, importer, runbook (validation)

> **Testing Strategy (Lean 80/20 Model)** — build correctly (unit), validate in the real system (dev database,
> `npm run preview`), release safely (CI). Rows marked **DB** need the dev database; rows marked **FILE** need the
> client stock export. A row that cannot run because its prerequisite is absent is reported **UNVERIFIED**, never
> PASS.

## Setup (once, before any row)

1. Work on the slice branch with a clean tree (`git status --short` prints nothing).
2. **Process environment (CLAUDE.md, one variable at a time, host only).** For each of `DIRECT_URL` and
   `DATABASE_URL`: `if printenv "$v" >/dev/null 2>&1; then printenv "$v" | sed -E 's#.*@([^:/?]+).*#\1#'; else echo "$v unset"; fi`.
   If either is set and is not the `.env` dev host, prefix every DB command below with
   `env -u DIRECT_URL -u DATABASE_URL`.
3. **DB rows only.** Confirm `.env` exists and its `DIRECT_URL` host is `ep-dry-morning-zab7dx08`; confirm that host
   appears in neither `secrets/staging.vars` nor `secrets/production.vars`; run `npx prisma migrate status` and read
   the datasource host it prints. If `.env` is absent every DB row is **UNVERIFIED**. Never accept a `migrate reset`.
4. **Row counts before anything runs (DB).** Run `npx tsx scripts/verify-catalogue-import.ts --snapshot
   .import-reports/before.json`; it records `Vendor`, `VendorDomain`, `Product`, `Category`, `Inventory` and
   `ProductRestrictionAuditLog` counts per vendor.
5. **Fixtures.** Synthetic source files are generated by the test suite from code (no client data). The client
   export and the test profile live **outside the repository** (for example `~/onboarding/`). The test profile is
   built from ADR-007's table: `byDepartment` TOBACCO and ALCOHOL `AGE_RESTRICTED`, INSTANT LOTTERY `PROHIBITED`,
   PHONE CARDS, NEWS, E-PAY and STAMPS `NOT_DELIVERABLE`; `uncertainDepartments` `["DEFAULT"]`; `columns` plu `PLU`,
   name `Description`, price `Price`, department `Dept`, subDepartment `SubDept`, vat `VAT`; `unit.defaultLabel` `each`.
6. **Test manifest** (outside the repository): id `e8a3b100-0000-4000-a000-0000000005a1`, slug `aheedsuperstore`,
   name `Aheed Super Store`, host `aheedsuperstore.localhost:8787`, branding copied from the `Forest Green` block
   in `prisma/seed.ts`, and `placeholders` listing `config.deliveryFeePence`, `config.freeDeliveryThresholdPence`,
   `config.minimumOrderPence`, `deliveryPrefixes`, `config.senderEmail` and `footer.location`.

## Notes for the validator

- This slice never touches staging or production. If any command prints a host other than the dev host in Setup 3,
  stop, report it, and do not continue.
- The test vendor and its rows are **left in place** at the end. Removing them is a separate request that needs
  explicit owner approval (see the runbook's Rollback section); do not clean up.
- Setup 3's host confirmation cannot be made in the cloud session (no `.env`); run the DB rows on the owner's
  machine, or report them **UNVERIFIED**.
