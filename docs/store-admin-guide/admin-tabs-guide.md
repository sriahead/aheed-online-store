# Store Admin Management Guide

Welcome to the **Store Admin Panel**. As a store manager or administrator for a specific vendor, you have access to advanced configuration tabs to manage the business logic and presentation of your storefront.

## Store Configuration & Branding
- **Delivery Rules:** Set your store's standard Delivery Fee, Free Delivery Threshold, and Minimum Order Amount.
- **Delivery Areas:** Define the specific postcode prefixes (e.g., "MK") where you offer delivery.
- **Storefront Branding:** Customize the visual identity of your online store. You can update the store name, tagline, logo, and core brand colors.
- **Promotional Banners:** You can configure the text that appears in the homepage header banner.

## Catalogue & Categories
- **Catalogue:** Add and edit product listings. You can define the product's name, description, and price.
- **Product Flags:** Mark products with special badges such as *Fresh*, *Organic*, or *Halal*. 
- **Featured Rail:** Check the "Featured" flag to place specific products on the homepage's featured carousel.
- **Categories:** Organize the storefront hierarchy (e.g., *Fresh Produce*, *HMC Halal Meat*) to help customers navigate. You can create sub-categories for finer control.

## Promotions, Loyalty, & Discounts
- **Homepage Promotions:** Create visual promotions for the homepage slider. You can upload an image, write a title, and define the link URL customers are taken to when clicked.
- **Discounts:** Create promotional codes (e.g., `SUMMER10`) that offer either a percentage or fixed amount off. You can set minimum cart thresholds, start and end dates, and limit the maximum number of times a code can be used globally or per customer.
- **Loyalty Program:** If enabled, you can define how many points are earned per pound spent, and how much points are worth when redeemed. You can also create Loyalty Tiers (e.g., Silver, Gold) with spend thresholds and point multipliers to reward your best customers.

## Orders & Fulfillment
While staff handle the day-to-day picking, you can view the macroscopic order flow, issue full refunds via the payment provider (Stripe), and monitor overall operations.

## Team Management
- **Staff Accounts:** Invite new staff members and manage their roles securely. You can assign users as either *Staff* (who see the fulfillment interface) or *Admins* (who see this configuration interface).
